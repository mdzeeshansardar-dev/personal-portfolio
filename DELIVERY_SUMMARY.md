## 🚀 Getting Started

### Installation (3 commands)
```bash
cd c:\CODING\portfolio-app
npm install
npm run dev
```

### Key Files to Edit First
1. `src/components/Hero.jsx` - Add your name, email, social links, avatar
2. `src/components/Projects.jsx` - Update project details
3. `index.html` - Update meta tags and JSON-LD schema

### Deployment (One Click)
- **Vercel**: Push to GitHub → Import on Vercel → Done (auto-deploys)
- **Netlify**: Run `netlify deploy --prod --dir=dist`
- **GitHub Pages**: Run `npm run deploy` (after setup in docs)
