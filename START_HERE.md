🚀 DEPLOYMENT - CHOOSE YOUR PLATFORM

  VERCEL (Recommended - One Click Deploy)
  ─────────────────────────────────────
  1. Push to GitHub
  2. Go to vercel.com
  3. Import your repo
  4. Auto-deploys! 🎉
  └─ Details in README.md

  NETLIFY
  ──────
  1. Install: npm install -g netlify-cli
  2. Build:  npm run build
  3. Deploy: netlify deploy --prod --dir=dist
  └─ Alternative: Connect GitHub for auto-deploy

  GITHUB PAGES
  ────────────
  1. npm install -g gh-pages
  2. npm run deploy
  └─ Full instructions in README.md

  TRADITIONAL HOSTING
  ───────────────────
  1. npm run build
  2. Upload dist/ folder via FTP/cPanel
  3. Configure .htaccess (included instructions)
  └─ Works on all shared hosting

❓ TROUBLESHOOTING

  npm install fails?
  └─ Try: npm cache clean --force

  Styles not loading?
  └─ Restart dev server: npm run dev

  Dark mode not working?
  └─ Clear localStorage: localStorage.clear()

  Port 5173 already in use?
  └─ npm run dev -- --port 3000

  More help?
  └─ See README.md troubleshooting section
